## 🛡️ Security Hardening & Production Readiness

The platform has undergone deep security auditing and hardening across 12 critical subsystems:

1. **Certificate Privacy & Field-Level Access Control**:
   - Draft certificates are strictly filtered out from public verifiers and students via `canReadCertificates`.
   - Linked student identity fields (email, user ID) are masked on public verification routes via `canReadCertificateStudent`.
2. **Issued Certificate Immutability**:
   - `Certificates.ts` beforeChange hooks permanently lock all critical fields (`studentName`, `course`, `issuedDate`, `qrCode`, `certificateId`) once issued (`isIssued: true`), preventing retroactive modifications even during user profile updates.
3. **Collision-Resistant Cryptographic IDs**:
   - Replaced random four-digit IDs with high-entropy identifiers formatted as `CUH-{YEAR}-{COURSE}-{BASE36_TIMESTAMP}-{RANDOM_HEX}`, verified across 5,000 continuous issuances with zero collisions.
4. **Server-Side Admin Route Protection**:
   - Custom admin hubs (`/admin/certificate-hub`, `/admin/contact-hub`, `/admin/notices`) are gated by [`AdminLayout`](file:///D:/Codingclubcuh/src/app/(app)/admin/layout.tsx). Unauthenticated visitors are redirected to `/admin/login`, students are redirected to `/student`, and pages are forced to dynamic server-rendering (`ƒ Dynamic`).
5. **Cross-Instance Atomic Rate Limiting**:
   - Mutation routes (`/api/contact`, `/api/auth/forgot-password`, `/api/chat`) are protected by an atomic PostgreSQL rate-limiting table (`rate_limits`) with IP validation and fail-open in-memory resilience.
6. **Serverless Filesystem Elimination**:
   - Migrated all legacy JSON filesystem stores into PostgreSQL Payload collections (`contact_messages` and `sent_notices`), ensuring seamless execution in serverless AWS/Vercel lambda environments.
7. **Gemini API Key Isolation**:
   - Transferred Gemini execution entirely to the server (`GEMINI_API_KEY`), removing client-bundle exposures while maintaining fallback offline heuristics.
8. **Batch Media Ingestion Security**:
   - Admin-only authorization, 10MB per-file size caps, max 20 files per batch, MIME validation, and file magic-byte inspection.
9. **Next.js Image Optimization**:
   - Optimized image delivery with AVIF/WebP formats and restricted remote hostname patterns.

## 🎓 Certificate & Verification Ecosystem

A complete pipeline designed specifically for Coding Club CUH workshops, bootcamps, and hackathons:

1. **Enrollment**: Students log in and register for active club courses (`/courses/[slug]`).
2. **Eligibility & Evaluation**: Instructors track attendance and mark eligible students inside the **Certificate Hub** (`/admin/certificate-hub`).
3. **One-Click Batch Issuance**:
   - Generates collision-resistant IDs (`CUH-2026-CP-XXXXX`).
   - Attaches digital signatures (Instructor, Faculty Coordinator, Student President).
   - Generates a scannable QR code encoding `https://codingclubcuh.online/verify/[id]`.
4. **Hard-Copy Certificate Ingestion**:
   - Allows admins to upload scanned physical certificates to Cloudinary with metadata.
5. **Instant Automated Emailing**:
   - Nodemailer dispatches responsive HTML congratulatory emails with direct download links.
6. **Public Verification & Vector PDF**:
   - Recruiters and students verify credentials anytime at `/verify/[certificateId]` and download clean, vector-accurate client-side PDFs via `jsPDF`.

## 🚀 Quick Start

### 📋 Prerequisites

- **Node.js**: `>= 20.0.0`
- **Package Manager**: `pnpm` (recommended), `npm`, or `yarn`
- **Database**: PostgreSQL (e.g. [Supabase](https://supabase.com))
- **Cloud Media**: [Cloudinary](https://cloudinary.com) account

### 🛠️ Step-by-Step Installation

1. **Clone the Repository**
   ```bash
   git clone https://github.com/CodingClubCUH/Codingclubcuh.git
   cd Codingclubcuh
   ```

2. **Install Dependencies**
   ```bash
   pnpm install --frozen-lockfile
   ```

3. **Configure Environment Variables**
   ```bash
   cp .env.example .env
   ```
   *Configure your credentials inside `.env`:*

   | Variable | Required | Description | Default / Example |
   | :--- | :---: | :--- | :--- |
   | `DATABASE_URI` | **Yes** | PostgreSQL connection pooler URI | `postgresql://postgres.[id]:[pwd]@aws-0-ap-south-1.pooler.supabase.com:6543/postgres` |
   | `DIRECT_URL` | **Yes** | Direct PostgreSQL session URI | `postgresql://postgres:[pwd]@db.[id].supabase.co:5432/postgres` |
   | `PAYLOAD_SECRET` | **Yes** | Encryption secret for auth & sessions | `your-secure-random-payload-secret` |
   | `NEXT_PUBLIC_SERVER_URL` | **Yes** | Base URL (`http://localhost:3001` for dev, `https://codingclubcuh.online` for prod) | `http://localhost:3001` |
   | `CLOUDINARY_CLOUD_NAME` | **Yes** | Cloudinary Cloud Name | `your-cloud-name` |
   | `CLOUDINARY_UPLOAD_PRESET`| **Yes** | Cloudinary Unsigned Upload Preset | `your-upload-preset` |
   | `GEMINI_API_KEY` | Optional | Google Gemini API key (Server-only) | `AIzaSy...` *(Built-in smart fallback if omitted)* |
   | `SMTP_USER` / `SMTP_PASS` | Optional | Gmail App Password for cert emails | `codingclub@cuh.ac.in` / `16-char-app-password` |
   | `SMTP_FROM` / `SMTP_HOST` | Optional | SMTP sender address and host | `"Coding Club CUH" <codingclub@cuh.ac.in>` / `smtp.gmail.com` |

4. **Run Automated Test Suite**
   ```bash
   pnpm test:int
   ```
   *(Executes all 93 unit and security regression tests)*

5. **Launch Development Server**
   ```bash
   pnpm dev
   ```
   Navigate to [http://localhost:3001](http://localhost:3001) in your browser.

> [!TIP]
> Access the **Payload CMS Admin Panel** at [`http://localhost:3001/admin`](http://localhost:3001/admin) to manage club data and credentials.

<div align="center">

| Area | Technologies |
| :--- | :--- |
| **Core Framework** | Next.js 15.5 (App Router), React 19.1, TypeScript 5.7 |
| **Headless CMS** | Payload CMS 3.88 (Lexical Rich Text, Live Preview, Custom UI Components) |
| **Database & ORM** | Supabase PostgreSQL (`@payloadcms/db-postgres`), Transaction Pooling (:6543), Drizzle ORM |
| **AI & Mentorship** | Google Gemini Generative AI (`gemini-flash-latest`), Server-Side Execution |
| **Cloud Media & CDN** | Cloudinary API, Batch Upload Handlers, Sharp Image Processing |
| **Styling & Aesthetics** | Tailwind CSS v4, Ambient Spotlight Glow, Radix UI Primitives, Lucide Icons |
| **Animations & FX** | Motion (`motion/react` + `framer-motion`), Magic UI Primitives, Web Audio API |
| **Credentials & PDF** | jsPDF, `qrcode.react`, Nodemailer (TLS/SMTP Dispatch) |
| **Testing & Quality** | Vitest 3.2 (93 Passing Tests), ESLint 9 |
| **Deployment** | Vercel (Optimized Serverless Functions), Next-Sitemap |

</div>

## 📜 Available Scripts

| Command | Action |
| :--- | :--- |
| `pnpm dev` | Starts development server on port `3001` with `--no-deprecation` |
| `pnpm build` | Compiles production application and builds static XML sitemaps |
| `pnpm start` | Launches production server on port `3001` |
| `pnpm test:int` | Runs complete 93-test Vitest integration and security regression suite |
| `pnpm lint` | Analyzes code for issues with ESLint |
| `pnpm lint:fix` | Automatically fixes ESLint rule violations |
| `pnpm generate` | Regenerates Payload types and admin import maps |
| `pnpm generate:types` | Generates TypeScript definitions from CMS collections |
| `pnpm generate:importmap` | Rebuilds Payload admin component import map |
